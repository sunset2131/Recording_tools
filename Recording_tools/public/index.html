      操作说明

      1. 输入网址（可选）和流程名称，点击「开始录制」；不填网址则打开空白浏览器，手动导航到目标系统
      2. 浏览器自动打开，在浏览器中像平时一样正常操作（登录、点菜单、填表单…）
      3. 点击新链接打开的新标签页也会自动录制，无需手动切换
      4. 操作完成后关闭浏览器窗口即结束录制，JSON 文件自动保存
      5. 在下方「录制结果」中点击「📁 打开文件夹」获取 JSON 文件
      6. 将 JSON 文件交给开发人员用于自动化测试
      💡 录制说明：
      • 每次点击/输入/选择操作，自动记录该元素的 7 种定位（id、class、css、xpath、aria、placeholder、name）和 12 种属性
      • 新标签页自动监听，无需手动操作
      • 手机号、密码、验证码等敏感操作正常录制，开发人员处理时会自动脱敏
      • 如遇弹窗（滑块验证、短信验证等），直接手动操作，会正常录进脚本
